## 🚀 Things I've Built

### 🧠 NeuroSpeech

A project I've been building around speech practice and analysis.

It uses Whisper for transcription and explores pronunciation feedback, IPA phonetics, speaking rate, pauses, and progress tracking.

`Python` `Whisper` `Streamlit` `Docker`

[View Repository](https://github.com/parth656/neurospeech) · [Try Live Demo](https://huggingface.co/spaces/parthbijpuriya/neurospeech)

### ✈️ QuanTrip AI

An AI travel planner that turns a simple trip request into a structured itinerary using LLMs.

It started as an experiment in using LLMs for something more practical than a basic chatbot.

`Python` `LLMs` `LangChain` `FastAPI`

[View Repository](https://github.com/parth656/QuanTrip)

### 🤖 RAGHAVA Bot

A Q&A project where I experimented with combining **keyword search and vector search**, with LLMs generating the final response.

`Flask` `Gemini` `Ollama` `Vector Search`

[View Repository](https://github.com/parth656/RAGHAVA-BOT-Q-A)

### 📚 LTM-RAG

My exploration of an end-to-end RAG pipeline:

```text
Documents → Chunking → Embeddings → Vector Search → Retrieval → LLM
```

I built it to understand how the different pieces of a RAG system fit together.

`LangChain` `ChromaDB` `Hugging Face` `Gemini`
